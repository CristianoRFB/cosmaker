# Cosmaker OS

Estrutura inicial completa para desenvolvimento do sistema de gestão de ateliês/cosmakers.

## Ordem recomendada
1. Leia `docs/initial/README.md`.
2. Consulte `docs/initial/estruturas/sistema.txt`.
3. Consulte `docs/initial/estruturas/firebase.txt`.
4. Use os diagramas e mockups em `docs/initial/diagramas` e `docs/initial/telas` como referência visual.
5. Implemente por módulo, começando por autenticação, tenant/ateliê, clientes, solicitações, orçamentos e pedidos.

A árvore contém páginas, módulos, serviços, repositories, Firebase Functions, regras, testes, scripts e CI/CD como placeholders organizacionais.
