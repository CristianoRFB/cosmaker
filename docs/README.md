# Documentação

- `initial/`: briefing inicial, diagramas e telas de referência.
- `architecture/`: decisões arquiteturais e C4.
- `domain/`: regras por domínio.
- `api/`: contratos HTTP/webhooks.
- `security/`: autorização, privacidade e threat model.
- `testing/`: estratégia de testes.
- `operations/`: deploy, ambientes, backup e observabilidade.
