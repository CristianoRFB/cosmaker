# Leads v0.2.0

Nenhum lead confirmado com evidência documental suficiente foi identificado para esta versão. O marco comercial não cria leads, importa contatos ou transforma tenants reais em demonstrações. O manifesto e o material anterior são preservados.

Aurora/Luna, as fixtures Premium/Trial/Demo e os estados restritos são dados sintéticos do Emulator. Zé Cosmaker/tenant original não é reclassificado automaticamente como lead, demo ou fixture. Conceitos visuais genéricos do produto não identificam cliente nem representam captação real.

Quando houver uma fonte confirmada, a estrutura documental por lead deve preservar origem e lacunas sem suposições:

```text
leads/<lead-slug>/
  LEAD_CONTEXT.md
  LEAD_REFERENCE_SUMMARY.md
  LEAD_VISUAL_DIRECTION.md
  captures/
  assets/
  generated/
```

`captures/` guarda apenas capturas reais de origem identificada; `assets/` preserva referências com origem; `generated/` contém peças rotuladas conceituais. Personalização visual não é screenshot nem demonstra entrega ao lead. Nenhuma pasta de lead nominal foi criada neste goal.

Consulte o [manifesto global preservado](../../LEADS_MANIFEST.md), o [README da pasta](leads/README.md) e a [visão histórica](../v0.1.0/LEADS_OVERVIEW.md).
