# Rodrigues Art Studio — demo conceitual

Demo interativa NÃO OFICIAL de portfólio digital e gestão de encomendas para um estúdio de miniaturas e esculturas. Feita como prospecção; não é parceria confirmada nem produto em produção.

## Abrir
Abra `index.html` em navegador moderno ou publique esta pasta como site estático. Os caminhos estão em hashes:
- `#inicio`: landing e vitrine
- `#portfolio`: galeria filtrável
- `#encomenda`: solicitação de orçamento simulada
- `#acompanhar`: andamento no mesmo navegador
- `#gestao`: painel demonstrativo, sem senha, SEM backend e sem dados reais

## Roteiro de 90 segundos
1. Explore a galeria, filtre por categoria e clique em uma peça conceitual.
2. Clique `Usar como inspiração`, preencha os campos e crie um orçamento de demonstração.
3. Entre em `#gestao`, abra o pedido recém-criado, altere a etapa e salve.
4. Volte ao `#acompanhar` e consulte o código para verificar o novo status.
5. Restaure os exemplos fictícios pelo botão do painel para reiniciar a demonstração.

## Limitações
Todos os dados são simulados. A persistência local não sincroniza entre navegadores/dispositivos. Não há envio de mensagens, cobrança, criação de orçamento real, autenticação ou banco de dados. As imagens são SVGs ilustrativos originais, NÃO fotografias do artista; substituir apenas após permissão. Consultar `DESIGN.md` para decisões de UX, proveniência, limites e critérios.
